我们尊重你的隐私。本政策说明我们收集哪些信息以及为何收集。

## 我们收集什么
- 你通过表单或邮件提交的联系信息（如姓名、邮箱）。
- 基本分析数据（汇总的使用情况、访问页面）。我们不会发布任何可识别个人身份的分析数据。

## 我们如何使用数据
- 回复咨询与提供服务。
- 改进网站与我们的产品。
- 遵守法律义务。

## 邮件订阅（AIPE 动态）
- 如果你在 /zh/subscribe/ 订阅，我们会处理你的邮箱地址、所选语言、同意时间，以及用于防范垃圾信息的 IP 地址。
- 处理依据是你的同意。我们采用双重确认：在你通过确认邮件确认之前，不会发送任何内容。
- 订阅记录由我们的邮件服务商 Buttondown（Buttondown, LLC，美国）代表我们保存，并记录打开与点击情况以统计投递效果。向英国境外的传输依赖该服务商的标准合同保障。
- 每封邮件都包含退订链接，你也可以随时写信给我们撤回同意。退订后我们只保留一条屏蔽记录，以免误将你重新加入。
- 订阅与 AIPE 社区账号相互独立。

## AIPE 社区账号
- **账号数据**：你的邮箱地址、密码哈希或 GitHub 登录标识（由我们的身份验证服务商处理）以及登录记录。你的邮箱地址不会公开显示。
- **公开资料**：用户名、显示名称、头像、简介、兴趣、机构、链接以及已发布的贡献均公开。请只填写你愿意公开的内容。
- **你提交的内容**：草稿在发布前仅你本人和版主可见；已发布的贡献与评论公开。审核决定、说明与举报保存在仅版主可见的审核记录中。
- **处理依据**：履行与你之间提供社区服务的约定（使用条款），以及我们维护社区安全的正当利益（审核、限流与防滥用）。
- **保留与删除**：你可以随时在“我的账号”中下载数据并删除账号。删除将移除你的账号、资料、头像、贡献与评论；审核记录保留决定本身，但不再能识别到你。服务商保存的备份按其标准周期过期。
- **与营销分开**：注册账号不会让你订阅任何邮件。

## 服务提供方
- Supabase（Supabase, Inc.）托管社区数据库、身份验证、文件存储与服务器函数。
- Buttondown（Buttondown, LLC）向订阅者发送 AIPE 动态。
- GitHub（GitHub, Inc.）在你选择使用 GitHub 登录时进行身份验证，并托管本网站。
- Cloudflare（Cloudflare, Inc.）可能为表单提供防垃圾信息服务（Turnstile）。

部分服务商在英国境外处理数据；此类传输依赖其标准合同保障。

## 数据共享
我们不出售你的数据。仅在适当协议下与代表我们处理数据的服务提供方（如托管、邮件）共享，或在法律要求时共享。

## 数据保留
我们仅在实现上述目的所必需的时间内，或在法律要求的期限内保留数据。

## 你的权利
你可以请求访问、更正、删除或限制处理你的个人数据。
联系方式：**info@spiritconnect.co.uk**

## 安全
我们使用 HTTPS 与业界标准的防护措施。没有任何方法能做到 100% 安全，但我们会持续改进防护。

## 更新
我们可能会更新本政策，并在此发布带修订日期的新版本。
